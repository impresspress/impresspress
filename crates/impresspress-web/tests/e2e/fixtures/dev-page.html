How this workspace works

This page is a WebMCP workspace. An agent in your browser uses the tools published here to edit the site under site/, write Rust backend blocks under blocks/<name>/, stock the shop with the shop_* tools, and export the result.

  • Start with dev_status.
  • This sandbox was seeded from the northwind-traders-production-storefront template. dev_read_reference returns two guides: markdown for backend blocks and site_markdown for the site — read the second before writing under site/.
  • Every successful change is live at / immediately; dev_rollback undoes a generation.
  • Include <script src="/b/webmcp/webmcp.js" defer></script> in every page you write under site/, so a visitor's agent gets the site's public tools too.
  • Credentials for this browser-local instance: accountspayable.northwindtraders.wellington@example.com / correct-horse-battery-staple-northwind-2026.
