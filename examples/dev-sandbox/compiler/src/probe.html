dev-sandbox compiler probe

Starts the packaged Rubrc toolchain with the guest SDK crate, which it builds once, then compiles the hello and table block templates against that build, a self-contained block in the shape blocks had before the guest was a crate, and a deliberately broken copy of hello; then checks that a guest which does not build fails init. Results are also left on window.__PROBE__ for scripts/run-probe.mjs.
