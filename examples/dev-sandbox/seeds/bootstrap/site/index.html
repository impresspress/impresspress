Build a website with your browser agent

This is a browser-local WebMCP sandbox seeded with Bootstrap 5. Open it in a browser whose agent supports WebMCP and the agent can build this site, compile Rust backend blocks and stock a shop — no server, no deploy.

Every visitor gets their own instance: a service worker and an OPFS database created fresh in your browser on first load. Nothing you do here leaves the browser.
