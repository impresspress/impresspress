ImpressPress dev sandbox

This is a browser-local WebMCP development sandbox. Open this page in a browser whose agent supports WebMCP, and the agent can drive it directly — no server, no deploy, no account setup beyond what is already here.

Every visitor gets their own instance: a service worker and an OPFS database created fresh in your browser on first load. Nothing you do here leaves the browser.
