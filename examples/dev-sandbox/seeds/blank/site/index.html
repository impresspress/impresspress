ImpressPress dev sandbox

This is a browser-local WebMCP development sandbox. Open this page in a browser whose agent supports WebMCP, and the agent can drive it directly — no server, no deploy, no account setup beyond what is already here. An agent without WebMCP runs the same tools from the Tool console on the workspace page.

Every visitor gets their own instance: a service worker and an OPFS database created fresh in your browser on first load. Nothing you do here leaves the browser.

Getting in

Open workspace signs you in: there is no form and nothing to type. When the session expires, follow it again. An agent reading this page should start with /llms.txt.
